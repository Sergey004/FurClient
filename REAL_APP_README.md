# FA Nexus - Fur Affinity Client

Полнофункциональный клиент для Fur Affinity с реальными данными из сайта.

## Возможности

✅ **Аутентификация** - Безопасный вход в аккаунт FA
✅ **Галерея** - Просмотр подач в реальном времени
✅ **Поиск** - Полнотекстовый поиск по названиям, авторам и тегам
✅ **Уведомления** - Система уведомлений FA
✅ **Комментарии** - Загрузка и отображение комментариев
✅ **Кэширование** - Кэшируются данные для быстрого доступа
✅ **SFW Фильтр** - Опция скрытия взрослого контента
✅ **Кроссплатформа** - Web приложение (React + Vite)

## Установка

```bash
# 1. Установить зависимости
npm install

# 2. Создать .env файл (уже создан)
# Отредактировать если нужно:
cat .env

# 3. Запустить dev сервер (фронтенд + бэкенд)
npm run dev
```

## Запуск

### Development (оба сервера вместе)
```bash
npm run dev
```

Откроется:
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001/api

### Отдельный запуск

```bash
# Только frontend
npm run client:dev

# Только backend
npm run server:dev
```

## API Endpoints

### Аутентификация
- `POST /api/auth/login` - Вход в аккаунт

### Подачи
- `GET /api/submissions?page=1&filter=all` - Получить список подач
- `GET /api/submissions/:id` - Деталь подачи
- `GET /api/submissions/:id/comments` - Комментарии подачи

### Поиск
- `GET /api/search?q=query&page=1` - Поиск подач

### Уведомления
- `GET /api/notifications?username=user` - Получить уведомления

### Утилиты
- `POST /api/cache/clear` - Очистить кэш
- `GET /health` - Проверка здоровья сервера

## Использование

### Вход в аккаунт
1. Откройте http://localhost:3000
2. Введите ваше имя пользователя FA
3. Введите пароль
4. Нажмите Login

### Просмотр подач
1. На главной странице вы увидите галерею подач
2. Кликните на подачу для просмотра деталей
3. Прокрутите вниз для просмотра комментариев

### Поиск
1. Используйте поле поиска в шапке
2. Введите название, автора или тег
3. Результаты обновятся в реальном времени

### Фильтрация
- Используйте кнопки категорий (All, Digital, Traditional, Writing)
- Или включите/отключите SFW фильтр в настройках

## Разработка

### Технологический стек

**Frontend:**
- React 19
- TypeScript
- Tailwind CSS 4
- Vite 6
- Lucide React (иконки)

**Backend:**
- Express.js
- Cheerio (HTML парсинг)
- Axios (HTTP клиент)
- Node-cache (кэширование)

### Добавление новых функций

1. Если нужна новая API функция, добавьте маршрут в `server/api.ts`
2. Если нужен новый hook, создайте его в `src/hooks/useFA.ts`
3. Если нужен новый UI компонент, добавьте в `src/App.tsx`

### Тестирование API

```bash
# Проверить здоровье сервера
curl http://localhost:3001/health

# Поиск
curl "http://localhost:3001/api/search?q=wolf&page=1"

# Очистить кэш
curl -X POST http://localhost:3001/api/cache/clear
```

## Важно

⚠️ **Безопасность**: Учетные данные хранятся только в текущей сессии и не сохраняются на сервере.

⚠️ **Rate Limiting**: Fur Affinity может иметь ограничение частоты запросов. Не делайте слишком много запросов одновременно.

⚠️ **Парсинг**: Система парсит HTML сайта. Если структура сайта изменится, парсер может сломаться.
