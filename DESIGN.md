# Концепция Дизайна Мультиплатформенного Клиента "FurClient"

Данный документ описывает визуальную философию, дизайн-системы и особенности пользовательского интерфейса приложения **FurClient** — современного клиента для платформы Fur Affinity с возможностью симуляции различных целевых экосистем.

---

## 🎨 Визуальная Философия

Главная идея дизайна — **интерактивное исследование мультиплатформенности**. Интерфейс разделен на внешнюю управляющую оболочку в футуристично-темных тонах и адаптивный интерактивный фрейм, демонстрирующий поведение приложения на двух разных ОС.

### Ключевые аспекты визуального направления:
1. **Премиальный Темный Скевоморфизм Оболочки**: 
   Внешняя панель управления и меню опций выполнены в глубоких графитовых и угольно-черных тонах (`#0f0f11`, `#141414`) с тонкими полупрозрачными границами (`border-white/5`), создающими ощущение работы с профессиональным интерактивным терминалом разработчика.

2. **Выразительная Типографика**:
   * **Дисплейные заголовки**: Высокотехнологичные шрифты с уменьшенным межбуквенным интервалом (`tracking-tight`) для четкой иерархии.
   * **Технические блоки**: Дополнительное использование моноширинного шрифта "JetBrains Mono" для индикаторов состояния, счетчиков, путей разметки и параметров компиляции.

3. **Цветовое Кодирование Навигации**:
   Каждая секция и интерактивный элемент подсвечиваются мягким неоновым сиянием соответствующих акцентных оттенков:
   * **Синий / Голубой (Fluent Cyan)** — для секций WinUI 3 и управления сборкой Windows.
   * **Изумрудный (Material Green)** — для Android-системы и индикаторов статуса компилятора.
   * **Нейтральный Фиолетовый (Cupertino Purple)** — для системных уведомлений и элементов исходного кода.

## 💻 Дизайн-системы симулируемых платформ

FurClient не просто адаптирует верстку, а полностью воссоздает визуальный язык целевых операционных систем:

### 1. Windows 11 • Fluent WinUI 3 Layout
Режим эмуляции настольной ОС Windows 11 ориентирован на горизонтальное пространство и строгое соответствие руководствам **Microsoft Fluent Design**:
- **Элементы управления окном**: В правом верхнем углу смоделированы стандартные системные кнопки (минимизация, максимизация, закрытие).
- **Элемент Mica / Полупрозрачность**: Окна разделов используют наслаивание прозрачных плашек на глубокий фон.
- **Боковое меню**: Стандартный сайдбар с акцентной синей вертикальной линией (`border-[#60cdff]`) у активного пункта меню.
- **Сетка постов (Grid Layout)**: Многоколоночная адаптивная сетка карточек, которая элегантно перестраивается в зависимости от размера экрана, сохраняя компактное представление метаданных.
- **Кнопки и поля ввода**: Имеют фирменное скругление Windows 11 (`rounded-lg`) и нижнюю контрастную полосу синего цвета у активных текстовых полей.

### 2. Android • Material 3 / Material You Layout
Смартфонный интерфейс воссоздает современный язык дизайна от Google — **Material 3 (M3)**:
- **Нижняя панель навигации (Navigation Bar)**: Фирменная нижняя панель высотой 64px (`h-16`) с овальными пилюлями-индикаторами (`rounded-full`) вокруг иконок для активного состояния, соответствующая спецификации Material 3.
- **Карточки контента (M3 Cards)**: Скругления углов увеличены до `rounded-2xl` (24px по гайдлайнам Google). Тонкие границы `border-white/5` в сочетании с более мягкими тенями.
- **Интерактивные чипсы (Quick Filter Chips)**: Овальные фильтры категорий медиафайлов под строкой поиска со сменой фона на светлые оттенки (`bg-[#e8def8]`) при выборе.
- **Поля ввода и переключатели**: Круглые текстовые инпуты в форме капсулы и плоские переключатели с цветовым акцентом Material You Lavender.

## 🛠 Дизайн Интерактивных элементов

### Диалог Upload (Загрузка медиа)
Модальное окно выполнено с размытием заднего фона (`backdrop-blur-md`) и предлагает интуитивный опыт:
- **Drag-and-Drop область**: Мягкая штриховая граница с пульсацией, интерактивно реагирующая на перетаскивание файлов.
- **Поля тегирования**: Организовано свободное добавление тегов с кнопками быстрого удаления, окрашенными в яркие цвета для предотвращения случайного нажатия.

### Структурированная кодовая палитра
Режим просмотра исходного кода (вкладка "Структура Исходников") оформлен в виде интегрированной среды разработки (IDE):
- Древовидная папка файлов с иконками форматов (Dart, YAML, Markdown).
- Полнофункциональный интерактивный предпросмотр кода с подсветкой синтаксиса и строками нумерации.
